# Laien Zou — Personal Website

Personal website of Laien Zou, a Computer Science student at the University of Toronto (Specialist in Data Science & Computer Science).

**Live site:** https://stevenzou634.github.io

## Pages

- **About** — introduction, education and recent news
- **Projects** — course and personal projects with links to their repositories
- **Awards** — honors and awards
- **CV** — opens my resume as a PDF

## Built with

- Plain HTML, CSS and a small amount of JavaScript (no frameworks or build step)
- Responsive layout using CSS Grid and Flexbox
- Light / dark mode toggle that remembers the visitor's choice
- Hosted on GitHub Pages

## Files

| File | Purpose |
| --- | --- |
| `index.html` | About page (home) |
| `projects.html` | Projects page |
| `awards.html` | Awards page |
| `style.css` | Shared styles for all pages |

| `resume.pdf` | Resume opened by the CV link |
| `avatar.jpg` | Profile photo |
| `favicon.svg` | Browser tab icon |

## Run locally

No installation needed. Open `index.html` in a browser, or use the **Live Server** extension in VS Code for automatic reload on save.

## Updating the site

- **Small text edits:** open the file on GitHub, click the pencil icon, edit, then commit.
- **Larger changes:** edit locally, then use **Add file → Upload files** to replace the changed files (same file names), and commit.
- **New resume or photo:** upload a file with the same name (`resume.pdf` or `avatar.jpg`) to overwrite the old one.

GitHub Pages redeploys automatically within a minute or two after each commit.
